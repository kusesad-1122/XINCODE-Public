v1.14.12026-09-07

在线插件市场：3 个 → 27 个，全部实测可用

  • 注册表扩至 27 个、8 分类（气象预报/金融财经/知识百科/影音资讯/实用工具/饮食健康/游戏娱乐/开发运维），每个端点上线前都调通返回 200 才收录；世界时钟等 4 个已死服务剔除，Frankfurter 换新域名。
  • 注册表升 version 2：新增分类与下载/星/收藏/发布时间保留字段——公共源没有这些数就不编造，有数的条目 UI 自动出现对应排序与徽标。
  • 在线插件请求补默认 UA（部分公共 API 拒绝无 UA 请求）；校验挪到路径替换之后，守卫看的是最终 URL。

插件页：一项一页 + 筛选

  • 拆四个页签：连接器 / MCP / 在线插件 / 技能包，各占一页，页签带计数。
  • 在线页新增搜索框（名/简介/分类）、分类 chips、免登/需 Key 筛选、排序（名称/分类；星数/下载有数才出现）。
  • 在线卡片徽标行：分类 · 授权 · 星/下载（有数才显示）。

技能：场景自动引用

  • 每回合按用户输入自动匹配技能（点名最优先 + 简介交集 + 常用者优先），命中附用法摘要进本回合上下文，不污染冻结前缀；未命中零成本，原 /技能名 精确调用不变。

修：子智能体管理页恒空

  • 列表从未加载导致页永远是空的——现按页打开即查，增删改即时刷新；内置四个角色不受影响。

用量分析页优雅化

  • 六散盒改 Hero 总览卡（累计大字 + 调用/命中/日均/花费）；三段加 accent 标题；柱状图改圆头渐显；成本改 Top3 明细。

代码索引：按需自建

  • code_graph 查询时库空就地建一次（增量指纹与文件上限复用既有逻辑），模型不用先去索引屏；建失败如实返回空，不炸。
v1.14.02026-09-06

在线插件：云端上架，应用无需发版

  • 新形态 ONLINE：插件市场目录从仓库 docs/plugins/registry.json 实时拉取，失败自动回退本地缓存——云端上架新插件，用户侧直接可见可用，不用等发版。
  • 远程工具注入：在线插件 = 远程 OpenAPI 轻量子集，工具列表动态转成 Tool 注入 Agent；执行时直连插件云端（GET query / POST JSON），响应截断 4000 字符防爆上下文。
  • 出站守卫 NetGuard：仅放行 http(s) 公网，localhost/环回/私网/保留地址一律拒绝（SSRF 防护）。

运行链：双向层（以前单向接口接不住长任务）

  • 通知栏"中断"按钮：任务跑起来后，切后台、杀 UI，通知栏一点即真停——停的是执行链本身，不是只关界面；超时与手势中断统一走同一入口。
  • 此前：停的办法只有回 App 点停止，UI 死了就只能干等或强杀进程。
  • 现在：新增 App Server 双向层——产品侧可启动/中断/追发输入/回审批，核心侧持续推送模型输出、工具进度、文件改动、审批请求。

运行链：任务身份（多轮不断片）

  • 同一任务的多轮执行有了 Thread/Turn 身份：Thread 是任务档案，Turn 是其中一轮——修 Bug 时第一轮查根因、第二轮按证据改码，第二轮自动继承第一轮结论，不再全文重灌。
  • 效果：跨轮引用不断档，且提示词 token 实打实下降。

运行链：调度与执行分离 + 真审批

  • 工具调度器只答"交给谁"：纯函数、无副作用；新增工具零权限代码，意图与管控彻底分家。
  • 执行管理器管边界：审批→选执行域→运行固定顺序，会话归属、前后钩子、计时收敛一处。
  • 审批是执行链真暂停：敏感操作 Turn 停在等待位，通知栏同意/拒绝直达执行链——无回执不执行（飞行模式点同意也无效），拒绝后模型基于拒绝原因换方案重判。此前确认框更像"心理按摩"，后端并没真停住。

运行链：停止条件与失败语义

  • 结果必回模型：只要发起了工具调用，模型必须看到执行结果才允许结束；最终回答守卫防止"有结果没送达就结案"。
  • 失败不再静默：模型调用失败（网络/服务异常）导致工具结果没送达时，记明确错误、不清断点——此前会静默结束，看板甚至记成"成功"（已随本版修正）。

运行链：事件溯源、恢复与分支

  • 运行流水（用户输入/模型输出/工具调用与结果/审批请求与裁决/Turn 起止）只追加落盘：模型上下文可以压缩，系统到底经历过什么永久保留。
  • 强杀/重启后悬挂任务自动回收，可看记录从断点续跑；支持 Fork——从某轮复制前缀换方案分支重试，前文不丢、未来事件不串。
  • 恢复 = 读取→解析→重建，不是读内存快照（此前切后台久了回来只能重跑）。

向 Codex 学习借鉴的三块行级逻辑（Apache-2.0 署名，独立文件）

  • 执行策略判定：allow < prompt < forbidden 越严越胜；按命令首词索引的前缀规则（含多备选词）；网络 host 归一化（去 scheme/端口、IPv6 去括号、小写、禁通配符）；域名黑白名单编译（Allow 进白、Forbidden 进黑、Prompt 两边不进）；策略自带正反例自检——规则写漏/写宽在加载期就炸，不在线上爆。裁决直挂既有闸门类型（Allow/NeedConfirm/Denied）。说明：Starlark 策略文件解析器没搬（解释器太重，用 Builder API 等价组装）；host 可执行路径归属没搬（POSIX PATH 语义，Android 上搬来是错的）。
  • 权限求交：只收紧不放松；非法路径/不支持形状直接 fail-closed；网络取 AND（两边都开才开）；路径先归一化再比（.. 越界拒，/a/b 不覆盖 /a/bc）；默认拒绝。附工作区读写两种常用剖面。
  • Rollout 对齐：事件带 thread/turn/call 三 id，Begin 配 Running、End 配终态，靠 callId 配对；执行状态词汇与上游逐字一致（running/completed/failed/cancelled/aborted）；导出键向 Rollout JSONL 对齐，两边工具可互读。

开发者向

  • 新增可执行回归：HarnessDrillTest（Thread→Turn→事件→重建→未决审批→Fork→导出→回收全链演练）、ToolRouterTest（直命中/纠偏/未知三裁决）、既有 SchemaConsistencyTest 自动覆盖三张新表与五个索引的迁移↔实体一致性。跑法：./gradlew :data:testDebugUnitTest :core:testDebugUnitTest :security:testDebugUnitTest。
  • 数据库 v47→v50 自动迁移；在线插件动态注册的工具自动被统一派发观测覆盖。

官网站点

  • 移动端适配：Hero 贴边修复、汉堡菜单可点、去掉点按高亮、滚动渐显、锚点避让吸顶导航。
  • 补回误删的 script 闭合标签（菜单与版本号显示恢复）。

升级提示

  • 首次启动会做数据库迁移（v47→v50），稍慢属正常；数据保留，以上能力自动生效、无需改设置。
  • 本版含数据库结构变更：如需降级回旧版，旧库会被改名备份后重建（数据不自动回来），请先确认重要内容已留档。

v1.13.62026-09-06

真实 bug 修复批(全模块排查)

  • 对话时序(彻底修)：1.13.4 的渲染层修法对「模型不说话直接调工具」这一最常见场景无效——结论文字流进了回合开始就创建的占位消息。现改为数据层修复：工具先到时作废空白占位段，结论懒创建为工具之后的新消息，流式进行中即正确，历史记录也不受影响。
  • 流式中删消息会写错行/崩溃：回合进行中删除任何消息会让流式写入的下标漂移(答案写进别的气泡、工具结果挂错卡片、极端时越界崩溃)。现流式期间一律拒绝删除(与上下文压缩的既有保护一致)。
  • 思考内容跨段重复：多段交错回合里,后段会重复显示前段已展示过的思考——现在每段只带自己的新增思考。
v1.13.52026-09-06

修复与思考样式对齐 Claude

  • 修复：v1.13.4 中设置页「插件」入口被误删的问题——现已放回「Agent 工具」分区第一行，打开设置即可见。
  • 思考样式对齐 Claude：收起时不再带底框，改为一条浅色摘要行（时钟图标 + 思考内容首句摘要 + 细箭头），点开才展开完整思考内容；无思考内容时回退显示「思考了 X 秒」。

Convention

我们怎么记录变更

  • 按用户能感知的结果写——先说"现在能做什么 / 修好了什么",再说实现细节。
  • 失败与取舍也写——例如某个公共 API 已经失效、某个方案被回退,都会留一条,而不是悄悄删掉。
  • 发布即附 APK——打 tag 时从 CHANGELOG 自动截取对应段落作为 Release 说明,人工只写一次。
