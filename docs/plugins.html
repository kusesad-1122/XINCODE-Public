插件、MCP 与技能包

插件页在应用里拆成四个页签:连接器、MCP、在线插件、技能包。这一页把当前清单列全,包含 27 个在线插件与它们的真实分类。

Connectors

连接器

需要账号授权的服务走 OAuth 设备流,Token 加密存在本机,同一个授权在多处复用。

GitHub 连接器

OAuth 设备流登录 GitHub(免手动建 Token):弹窗里展示用户码并跳转浏览器完成授权,结果自动回传。Token 经 Keystore 加密存储,远程 MCP 与 git 操作复用同一份授权。

连接器OAuth 设备流Token 加密存储

自定义 MCP 服务器

除内置清单外,还可以自行添加 MCP 服务器:本地 stdio 形态直接跑在本机,远程 HTTP 形态填地址即可。连接成功即把工具注册给 Agent,卸载即注销。

MCPstdioHTTP

MCP Servers

免鉴权 MCP,装完即用

下面这些服务器不需要你自己申 Key,装完握手成功就能被 Agent 调用。

GitHub 远程 MCP

官方远程 MCP,免 root / 免 node:AI 直接用 GitHub API 管仓库、PR、Issue 与文件。未登录时安装会先弹授权。

api.githubcopilot.com/mcp/

learn.microsoft.com/api/mcp

需要 Key 的插件(例如 Exa 神经检索),Key 经 Keystore 加密落库后只注入请求头,绝不进入模型上下文;响应统一截断 4000 字符,避免一次把上下文撑爆。
