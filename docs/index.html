02左右分栏 · Split

长任务跑得完,也停得住。

这个模板负责「解释 + 举证」:左边讲运行链的三条规则,右边用一次真实任务的流水面板,展示审批、续跑与多轮继承长什么样。

  • 通知栏一键中断——切后台、杀 UI 也能真停,停的是执行链本身,不是只关界面。
  • 敏感操作真审批——执行链真的暂停等你回执,无回执不执行;拒绝后模型基于拒绝理由换方案重判。
  • 多轮不断片——同一任务有 Thread / Turn 身份,第二轮自动继承第一轮结论,不再全文重灌。
  • 杀进程可续跑——运行流水落盘,可续跑、可分支重试;工具结果必回模型,失败明示不静默。

07折叠问答 · Accordion

常见问题。

这个模板负责「答疑」:安装、密钥、数据与更新这类高频问题折叠收起,展开即读,不占版面;答案与「上手」页保持一致。

必须 Root 才能用吗?

不必须。基础功能(对话、工具调用、插件、记忆)免 Root 可用;Root 之后终端与内置 Ubuntu 环境权限更彻底,适合编译、反编译这类重度场景。

应用自带模型额度吗?

不带。XINCODE 不内置任何托管密钥,也不代理你的请求——端点与 API Key 由你自己填,费用直接结算给你的供应商。

支持哪些模型服务?

OpenAI Chat Completions 兼容端点、OpenAI Responses、DeepSeek、Anthropic,以及自定义端点与模型清单。

手机上真能跑终端和构建吗?

可以。内置 root 终端;需要完整环境时一键部署 Ubuntu(root + chroot 自动完成),之后用 apt 装 JDK 等依赖,构建产物直接落在你的存储里。

我的数据会被上传吗?

对话内容只会发往你自己配置的模型服务;联网搜索与插件调用会把必要参数发到对应服务。没有广告 SDK、没有第三方分析、没有账号体系。

怎么更新到新版本?

应用内:设置 → 关于 → 检查更新;或从 Release 页下载签名 APK 覆盖安装。数据库升级会自动完成,记忆条目不会丢。
