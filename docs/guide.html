Install

安装应用

  1. 打开 Release 页(在新标签页打开),在最新版本里下载 app-release.apk(正式签名包)。
  2. 在系统里允许这次安装来源(Android 会就"未知来源"给出提示,安装后可收回)。
  3. 安装后首次启动,按下面的步骤填模型配置。
关于 APK 来源

只从本仓库的 Release 页或你自行构建的产物安装。第三方站点二次打包的 APK 无法保证未被改动——签名一旦不同,系统就不会允许覆盖安装。

First Run

首次配置

进入设置填写你自己的 LLM 供应商信息:端点 + API Key + 模型。

  • OpenAI Chat Completions——最常见的兼容路径,第三方中转同样适用。
  • OpenAI Responses——需要这一路径时选择「OpenAI Responses」,它会调用 /v1/responses,并把工具调用、结构化输出与流式事件转换成应用内部格式。
  • DeepSeek / Anthropic——按各自原生协议走。
  • 多供应商共存——可以同时配置多家,在对话里切换;自定义端点与模型清单也支持。
Key 存在哪里

API Key 只保存在设备上,经 Android Keystore 加密的配置存储落库;正式包不包含任何 Key,应用也不会把 Key 发到模型服务以外的地址。

Build from source

从源码构建

Debug 包不需要签名密钥,克隆下来就能编:

git clone https://github.com/kusesad-1122/XINCODE-Public.git
cd XINCODE-Public
./gradlew :app:assembleDebug
# 产物:app/build/outputs/apk/debug/app-debug.apk

需要 JDK 17 与 Android SDK(Platform 34)。若本机未安装 SDK,在项目根目录新建 local.properties 指向 SDK 路径:

sdk.dir=/path/to/Android/Sdk
关于 codegraph 内核

仓库的 CI 会先把 codegraph-kernel(Rust + tree-sitter)交叉编译成 arm64 的 .so 再打包,需要 NDK 27.2 与 aarch64-linux-android 目标。若本地构建提示缺少该产物,按 .github/workflows/build.yml 里对应步骤准备工具链即可。

工程是多模块 Gradle(Kotlin DSL)结构,模块职责见功能页的工程结构一节。

Signed release

打 Release 签名包

签名密钥是你的私有机密,永远不要提交进仓库——keystore.properties、*.jks、*.keystore 都已经在 .gitignore 里。

  1. 复制模板:cp keystore.properties.example keystore.properties
  2. 若还没有密钥,生成一个: 
    keytool -genkeypair -v -keystore xincode-release.jks \
  -alias xincode -keyalg RSA -keysize 2048 -validity 10000
  3. 把 keystore.properties 里的四项填成真实值(storeFile / storePassword / keyAlias / keyPassword)。
  4. 打包:./gradlew :app:assembleRelease,产物在 app/build/outputs/apk/release/app-release.apk。
请离线备份密钥与口令

.jks 与这些口令一旦丢失,将无法再为同一个应用发布更新(Android 只认同一把签名密钥)。若 keystore.properties 不存在,构建脚本会自动跳过签名配置,Debug 仍可正常构建。

FAQ

常见问题

必须 Root 才能用吗?

不必须。基础功能(对话、工具调用、插件、记忆)免 Root 可用;Root 之后终端与内置 Ubuntu 环境权限更彻底,适合要编译、反编译这类重度场景。

应用自带模型额度吗?

不带。XINCODE 不内置任何托管密钥,也不代理你的请求——你需要自己准备端点与 API Key,费用直接结算给你的供应商。

支持哪些模型服务?

OpenAI Chat Completions 兼容端点、OpenAI Responses、DeepSeek、Anthropic,以及自定义端点与模型清单。具体以当前版本的设置页为准。

手机上装得下开发环境吗?

可以。内置 root 终端,需要完整环境时一键部署 Ubuntu(root + chroot 自动完成),之后用 apt 装 JDK 等依赖。存储占用取决于你装了什么。

我的对话数据会被上传吗?

对话内容会发送到你自己配置的模型服务(否则模型无法回答),另外联网搜索与插件调用会把必要的查询参数发到对应服务。除此之外应用不做额外上报,也没有广告与分析 SDK。

插件为什么不用更新应用就能多出来?

在线插件目录从云端实时拉取,插件本身是远程 OpenAPI 的轻量子集,执行时直连插件服务。因此上架新插件不需要你重新装 APK。
