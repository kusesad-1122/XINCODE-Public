Runtime

长任务跑得完,也停得住。

手机上的长任务最怕两件事:你管不了它,它做得不明不白。XINCODE 把这两件事都写进了运行链。

  • 通知栏一键中断——切后台、杀 UI 也能真停,停的是执行链本身,不是只关界面。
  • 敏感操作真审批——执行链真的暂停等你回执,无回执不执行;拒绝后模型基于拒绝理由换方案重判。
  • 多轮不断片——同一任务有 Thread / Turn 身份,第二轮自动继承第一轮结论,不再全文重灌。
  • 杀进程可续跑——运行流水落盘,可续跑、可分支重试;工具结果必回模型,失败明示。

Changelog

迭代很快,条条有据。

每个版本都在仓库的 CHANGELOG 里写清楚改了什么、为什么改。下面是最近几个版本。

v1.14.12026-09-07最新

在线插件 3 → 27、技能场景自动引用

  • 在线插件注册表扩至 27 个 / 8 分类,每个端点上线前都调通返回 200 才收录。
  • 插件页拆四个页签,在线页加搜索、分类 chips、免登 / 需 Key 筛选与排序。
  • 每回合按输入自动匹配技能,命中附用法摘要进上下文,未命中零成本。
v1.14.02026-09-06

在线插件上线 + 运行链重构

  • 插件目录改为云端拉取,失败回退本地缓存;出站守卫 NetGuard 拒绝私网与环回地址。
  • 新增 App Server 双向层:通知栏可中断 / 追发输入 / 回审批,核心侧持续推送进度。
  • 任务有了 Thread / Turn 身份,多轮执行自动继承前轮结论。
v1.13.42026-09-06

对话体验与插件市场重构

  • 工具卡默认收起成一行摘要,计划卡默认折叠,多步工具收进「执行了 N 步」。
  • 思考折叠仿 Claude:一行摘要,点开才展开完整思考。
  • 对话产出(Artifacts)抽屉:列出本会话生成的文档、文件与图片。
