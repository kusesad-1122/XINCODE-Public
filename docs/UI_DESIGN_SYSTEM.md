# XINCODE 全局 UI 设计系统

本规范把聊天、设置、供应商、身份、工作流、统计和弹窗统一到同一套移动端视觉语言。实现入口是 `Theme.kt` 的 `XinTheme`，页面应优先使用 Material 组件与这里的全局 token，不再建立页面私有配色体系。

## 视觉方向

- 背景使用暖白纸张色，暗色使用近黑而不是纯黑。
- 主要文字为墨黑，次要说明为中性灰，品牌强调为低饱和橄榄绿。
- 状态只使用语义色:成功/完成为绿色，警告为黄色，失败/运行注意态为红色。
- 大面积容器使用 18–30dp 圆角；小控件使用 8–12dp 圆角。
- 边框保持 1dp 或更细，避免阴影堆叠。

## 字体

- `XinUiFont`:系统无衬线，用于标题、正文、表单、列表、按钮和中文界面。
- `XinCodeFont`:JetBrains Mono，只用于 Shell、代码、路径、终端输出和 diff。
- 默认正文 15–17sp、行高 22–26sp；页面标题 21–24sp；辅助标签 12–14sp。

## 组件规则

- 顶栏:左侧返回/导航，中间标题与可选副标题，右侧最多两个 40dp 操作。
- 列表与表单:使用 `MaterialTheme.shapes.medium` 或 `large`，内容边距 12–18dp。
- 聊天气泡:用户靠右、助手靠左；助手操作以时间线呈现，工具结果使用独立圆角面板。
- 输入器:上层消息输入与发送，下层保留模式/供应商、搜索、灵感、附件、语音和清空。
- 供应商头像:必须通过 `providerIconRes(supplierId)` 使用品牌图标；未知或自定义供应商回退到 XINCODE 启动图标，不生成近似品牌标识。

## 可访问性与交互

- 图标点击区域至少 40dp，所有可操作图标必须提供 `contentDescription`。
- 正文与背景、状态与背景必须保持可读对比；状态不能只靠颜色，需同时显示文字或图形。
- 模型、模式、联网搜索、语音、发送、停止、清空和新聊天必须连接真实状态，不做纯装饰控件。

## 例外

终端、代码块、diff、日志正文可以保留等宽字体与更紧凑密度；其页面导航、标题、表单和弹窗仍遵守全局 UI 规范。
