无障碍声明

本站按 WCAG 2.2 AA 的目标设计与自测。这一页说明已经做了什么、还有哪些已知限制,以及发现问题时怎么反馈。

本页目录

  1. 已经做到
  2. 已知限制
  3. 怎么自测的
  4. 反馈

What we did

已经做到

  • 语义结构——每页有唯一 h1,标题层级不跳级;使用 header / nav / main / footer 地标,页脚导航各有可读名称。
  • 跳到主要内容——键盘用户第一个 Tab 就能跳过顶栏直达正文。
  • 键盘可达——导航、主题切换、插件筛选与搜索框全部可用键盘操作;移动端菜单用 aria-expanded 标注状态,并可用 Esc 关闭、焦点回到触发按钮。
  • 焦点可见——所有可聚焦元素都有不依赖颜色的 3px 焦点外框。
  • 颜色对比——正文与次要文字对背景的对比度按 ≥4.5:1 选择,大字与图形按 ≥3:1;状态同时用文字或图形表达,不只用颜色区分。
  • 顺滑滚动与回到顶部——滚轮滚动带轻微缓动,站内锚点与「回到顶部」按钮都是平滑滚动;键盘翻页、触屏惯性、拖动滚动条仍是浏览器原生行为。关闭动效后改为即时跳转。
  • 动效默认开启,可一键关闭——滚动浮现、指挥室像素动画、数字滚动默认开启;顶栏的「动效」开关可随时关闭(关闭后所有循环动画与过渡冻结、元素直接可见),选择会保存在本机。
  • 深浅两套主题——跟随系统,也可手动切换并记住选择;两套都重新校过对比度。
  • 替代文本——装饰性像素素材标注为空替代文本并隐藏在辅助技术之外;整体场景提供一句话文字描述。
  • 不依赖脚本——正文、导航、下载链接与更新日志的静态快照在没有 JavaScript 时依然完整可读;筛选与实时数据只是增强。
  • 表单与状态提示——搜索框有可见标签与占位说明,筛选结果用 aria-live 播报,筛选按钮用 aria-pressed 表达开关状态。
  • 目标尺寸——按钮、导航项与筛选按钮的点击区域不小于 44×44px(紧凑链接不低于 26px 高)。
  • 页面语言——lang="zh-CN",便于屏幕阅读器选择正确的语音。

Known limits

已知限制

  • 像素场景是示意——指挥室为装饰性插画,不承载信息;四个角色名在页面上有等价文字说明。
  • 等宽字体不含中文字形——JetBrains Mono 只用于拉丁字母与符号,中文自动回退系统字体,因此终端示意里的中文宽度可能与纯等宽环境略有差异。
  • 实时数据依赖网络——版本号与更新日志会尝试从 GitHub API 获取最新内容;网络不可用或被限流时,页面显示的是构建时的静态快照。
  • 插件筛选的即时反馈——结果数量通过状态文本播报;若你使用极旧的浏览器,筛选可能不可用,此时所有插件卡片默认全部显示。

How we checked

怎么自测的

  • 逐页做键盘走查:Tab 顺序、可见焦点、Esc 关闭菜单、筛选按钮的开关状态。
  • 逐页检查标题层级、地标数量、图片替代文本、链接与按钮的可读名称。
  • 对文字与背景色做对比度计算,确认深浅两套主题都达到 AA。
  • 在窄屏(≤420px)与桌面宽度下检查横向溢出,确认没有需要横向滚动的正文。
  • 在系统开启"减弱动效"时确认页面静止且内容完整(0 个运行中的动画)。
  • 关闭 JavaScript 后逐页确认正文、导航、下载链接、插件清单与更新日志快照依然完整。
  • 分别在浅色、手动深色、系统深色(不依赖脚本)三种情况下抽取正文、按钮、卡片与页脚等 16 处取样点核对对比度。
  • 键盘走查确认 Tab 顺序为:跳到主要内容 → 站点标识 → 主导航 → 主题切换 → 下载按钮。

本站为静态站点:没有账号、没有表单提交、没有广告与第三方追踪脚本。
