Agent Core

多供应商模型,不被一家绑死

XINCODE 不内置任何托管密钥,也不绑定某一家模型服务。你在设置里填自己的端点、API Key 与模型清单,想换随时换。

  • OpenAI Chat Completions——最常见的兼容端点,第三方中转同样适用。
  • OpenAI Responses——走 /v1/responses,把工具调用、结构化输出与流式事件转换成应用内部格式。
  • DeepSeek / Anthropic——各自原生协议路径,不靠"兼容层"硬凑。
  • 自定义端点与模型清单——本地网关、自建服务、冷门兼容服务都能接。

API Key 只保存在设备上,经 Android Keystore 加密的配置存储落库;正式包不包含任何 Key。

Tool Loop

工具调用循环:结果一定回到模型

智能体的可信度取决于"它做的事有没有被如实记录"。XINCODE 的工具循环遵守三条纪律:

  • 结构化输出——模型返回的调用意图先解析成结构,再交给工具,不靠字符串猜。
  • 工具结果必回模型——失败就如实回失败与原因,不静默吞掉,也不伪造成功。
  • Prompt 缓存纪律——稳定的前缀不随每轮变化,缓存命中率因此可观测、可优化。

每次调用的耗时、产出与状态都留在对话时间线里,而不是被折叠成一句"已完成"。

Runtime

运行链:长任务跑得完,也停得住

手机上的长任务最怕两件事:你管不了它,以及它做得不明不白。运行链把这两件事都变成可操作的按钮。

通知栏就是控制面

  • 一键中断——切后台、杀 UI 也能真停。停的是执行链本身,不是只关掉界面。
  • 敏感操作审批——执行链真的停在等待位,通知栏同意 / 拒绝直达执行链;无回执不执行。
  • 拒绝后可重判——模型拿到拒绝理由后换方案重试,不是干等到超时。

任务有身份,多轮不断片

  • Thread / Turn——Thread 是任务档案,Turn 是其中一轮。修一个 Bug 时第一轮查根因、第二轮按证据改码,第二轮自动继承第一轮结论,不再全文重灌。
  • 续跑与分支——运行流水落盘,进程被杀后可续跑,也可以从某个分支点重试。

调度与执行分离

工具调度器只回答"交给谁"(纯函数、无副作用),执行管理器负责边界与顺序(审批 → 执行域 → 运行 → 收尾)。新增工具不必再写权限代码,意图与管控分开,行为可预测。

Plan & Collaboration

计划模式与协作模式

计划模式把任务拆成可视化任务卡,先看清路径再开工,改计划比改代码便宜。

协作模式下主脑把任务并行派发给多个专职子智能体,各自在自己的工位上干活,结果汇总回主脑。内置四个专职角色:

内置子智能体角色
角色负责什么
探索者在陌生仓库里找入口:目录结构、关键文件、调用链。
审查员挑毛病:边界条件、安全风险、被忽略的失败路径。
编码员按证据改代码,产出可运行的改动。
研究员查文档与外部资料,把结论带回主脑。

四个角色随应用内置,即使被误删,升级后也会按名自动找回。

Command Room

指挥室:进度看得见

子智能体不是日志里的四行字,而是四个工位上的像素小人。派活即联动:谁在检索、谁在跑测试、谁在等审批,一眼就能看出来。

指挥室是应用内的一层 WebView + HTML5 Canvas 场景,像素素材为可再分发的开放授权(角色 CC0、家具装饰 MIT),随仓库一并公开。

Terminal & Ubuntu

终端与 Ubuntu 环境

内置 root 终端;需要完整环境时,可一键部署 Ubuntu(root + chroot 自动完成),之后就像在一台小 Linux 机上工作。

  • 常用开发环境一键装——JDK、构建工具链等按需安装。
  • 技能包随装随用——安全代码审计、逆向分析、APK 构建 / 更新 / 反编译、LSPosed 模块开发。
  • 产物留在本机——APK、日志与中间文件都在你的存储里,不上传第三方。
免 Root 也能用

不 Root 时基础功能完整可用;Root 之后终端与 Ubuntu 环境的权限更彻底,适合重度场景。

Memory

长期记忆:互通,也隔离

记忆用两条腿走路:FTS 全文检索负责关键词命中,向量语义检索负责"意思相近"。两者结果融合后进入上下文,由模型判断该不该用。

  • 普通对话互通——日常对话之间记忆共享,不用每次重新自我介绍。
  • 项目对话隔离——项目内对话按项目归档,不把 A 项目的细节漏进 B 项目。
  • 精编两文件记忆——用户画像与近况由后台复盘分身维护,长期不变的事实与近期状态分开存。

Context & Cost

上下文与成本,全都摆在明面上

输入框旁边的圆环按占用率变色(绿 → 蓝 → 黄 → 红),不用点进设置就知道还剩多少余量。

  • 实时 token 与缓存命中——本轮用了多少、缓存省了多少,都看得见。
  • 可配置压缩阈值——接近上限时自动压缩,阈值由你定。
  • 人民币成本显示——按缓存感知计价,花的钱直接读得懂。

Automation

效率与自动化

  • 多引擎联网搜索——必应 / 百度 / 搜狗 / DuckDuckGo 结果融合,并抓取正文,不只给标题。
  • Goal / Work 多任务——丢一个目标进去,后台拆解执行;多任务并行不互相踩。
  • 定时任务——cron 表达式与 WorkManager 两种调度方式。
  • 语音转写——只在主动使用语音输入时录音。
  • 视觉与深度推理委托——把图片理解、复杂推理交给副模型,主模型专注编排。

Plugins & Skills

插件、技能与 MCP

插件页拆成四个页签,各占一页、带计数:

  • 连接器——GitHub 连接器走 OAuth 设备流,Token 加密存本机,与 Git 操作复用同一份授权。
  • MCP——本地 stdio 与远程 HTTP 双传输;免鉴权的官方远程 MCP 装完即用,也可自填地址接入自己的服务器。
  • 在线插件——远程 OpenAPI 轻量子集,目录从云端实时拉取,上架新插件不必等发版。
  • 技能包——六个内置技能可装卸;每回合按你的输入自动匹配技能,命中即附用法摘要进上下文,未命中零成本,也可以用 /技能名 主动调用。

Engineering

工程结构:多模块 Gradle

纯 Kotlin 原生,没有跨端框架,也没有为了跨平台而引入的抽象层。

模块与职责
模块职责
appAndroid 入口、Compose UI、智能体编排、指挥室 WebView
coreAgentCore、工具注册表、调度循环
provider各 LLM 供应商客户端(OpenAI 兼容 / Anthropic 等)
dataRoom 持久化、记忆(FTS + 向量)、记忆抽取
security权限模式、敏感操作门控、审计
tools内置工具实现
service前台服务、后台任务、通知
ui共享 UI 组件与主题

语言 Kotlin · UI Jetpack Compose · 存储 Room · minSdk 28 · targetSdk 34。
