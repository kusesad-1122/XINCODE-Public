Capabilities

不只是一个聊天框,
是一整套智能体工作台。

从工具调用循环到多智能体协作,从长期记忆到内置 Linux 环境——该有的底盘,一次配齐。

插件市场

连接器、远程 MCP 服务、技能包三类插件,一键安装卸载;需要授权的插件走设备流,浏览器登录后自动回传。

MCP 工具生态

本地 stdio 与远程 HTTP 双传输,GitHub、DeepWiki、Context7、Composio 等开箱即连,AI 直接调用真实工具。

多智能体协作

主脑拆解任务、并行派发给各司其职的子智能体,像素风「指挥室」里每个小人实时动给你看。

Goal 自主模式

丢一个目标进去,它自己拆解、执行、验收,后台跑完交付;计划卡全程可视,随时插话不打断。

记忆与上下文

全文 + 向量双检索的长期记忆,项目内隔离、对话间互通;上下文圆环与人民币成本实时可见,自动压缩。

终端与 IDE

内置 Ubuntu 环境与 root 终端,APK 构建、反编译、安全审计等技能随装随用——手机上真的能写代码。

Plugin Market
